五、常见问题与解决方案

连接失败怎么办？ 首先检查本地网络连接是否正常，尝试访问普通网站确认基础网络畅通。如果问题依旧，尝试切换不同连接协议（如从WireGuard切换到OpenVPN），因为某些网络环境可能会限制特定协议。还可以尝试更换端口，老D支持TCP 443端口，该端口通常不会被封锁。

速度慢如何优化？ 除了选择更近的节点外，还可以尝试以下方法：有线连接代替Wi-Fi，减少无线干扰；关闭后台大流量应用程序；更换DNS服务器为公共DNS（如Google DNS或Cloudflare DNS）；在客户端设置中启用“优化速度”选项。

移动设备使用注意事项 在手机上使用老D时，建议启用“按需连接”功能，仅在需要时启动VPN，节省电量。iOS用户需要注意，在中国区App Store可能无法直接下载，需要切换至其他地区账户。

安全性能否信任？ 老D采用无日志政策，不记录用户活动数据，且经过独立第三方安全审计。但没有任何安全工具是100%绝对安全的，建议对极度敏感的数据进行额外加密。

FAQ

Trojan 服务端出现 handshake timeout 如何处理？
该错误通常由网络延迟或证书配置不一致导致。请检查服务器带宽是否充足、TLS 证书链完整，并确保客户端 SNI 与证书匹配。必要时更换节点或优化拥塞控制算法。
Mellow TUN 模式的全局代理作用是什么？
TUN 模式拦截系统 IP 层的所有流量，实现全局代理效果。相比 SOCKS5 只作用于特定应用，TUN 可覆盖游戏、视频和浏览器流量，保证全系统科学上网体验稳定顺畅。
V2Ray 如何实现分流规则？
V2Ray 使用 routing 模块实现分流，可根据目标域名、IP、端口或协议类型决定流量走向。用户可自定义多个 outbound，并通过规则实现国内直连、国外代理等智能路由功能。
Netch 的全局代理与规则代理有何不同？
全局代理将所有流量都通过节点转发，而规则代理只针对指定 IP、端口或应用。全局代理适合游戏和全局科学上网，规则代理适合优化带宽和分流特定流量。
Hiddify Next 如何为不同用户设置流量限制？
管理员可为每个用户设置独立带宽限制和流量配额。超过限制时，可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提升整体网络效率和公平性。
Nekobox 如何设置分流规则？
Nekobox 提供图形化规则编辑界面，可基于 IP、域名、地区等条件创建分流规则。例如可设置国内直连、国外代理、特定网站走特定节点，操作直观。
Mellow 如何通过配置实现多出口分流？
Mellow 可在配置文件中定义多个 outbound，并结合 routing 规则实现按域名、IP 或策略组分流。这样不同类型的流量可走不同节点，提高使用体验。
Surfboard 的节点策略组如何提升使用体验？
策略组可将节点按延迟、用途或地理位置分类，通过规则自动选择最优节点。用户无需手动切换节点即可获得最佳速度和稳定性，提高浏览和观看流媒体的体验。
Potatso Lite 手动节点选择有什么好处？
手动选择节点可以让用户根据网络延迟和需求选择最优节点。适合节点不稳定或特定访问需求，灵活调整流量走向，提高访问速度和网络体验。
V2Ray 的 VMess over WebSocket 适合什么场景？
VMess over WebSocket 可以伪装成正常的 Web 流量，适用于被封锁较严格的网络环境。它通过将代理流量嵌入 WebSocket 协议中，使流量更难被检测和拦截。
